# Design Diagrams

This folder contains the five design diagrams for the Document Scanner & OCR Text Extractor project.

1. **architecture.svg** — high-level system architecture and module relationships.
2. **workflow.svg** — end-to-end processing workflow from input image to exported results.
3. **use_case.svg** — primary user interaction/use cases.
4. **class_diagram.svg** — software components/classes and their relationships.
5. **sequence_diagram.svg** — sequence of interactions during document scanning, OCR, and export.

The diagrams are kept as SVG files so they remain clear when viewed or scaled in a report or presentation.
